# Explain — Understand Any Code or Concept in Plain English

When a beginner shares code, a concept, or a term they don't understand, break it down so clearly that someone with zero experience gets it on the first read.

## What You Do

1. Read the code or concept the user shared (from args or from context)
2. Identify what is actually happening — don't assume the user knows the vocabulary
3. Explain it in **three layers**:
   - **The Big Picture** — what is this trying to accomplish? (1-2 sentences, no jargon)
   - **Step by Step** — walk through it line by line or concept by concept
   - **Real-World Analogy** — compare it to something from everyday life
4. Point out anything surprising, tricky, or commonly misunderstood
5. End with one "what to learn next" suggestion relevant to what was just explained

## Rules

- Never assume prior knowledge — define every technical term you use
- Use short sentences and simple words
- If the user shares code, quote the exact lines you're explaining
- Do not rewrite their code unless they ask — the goal is understanding, not correction
- Keep the entire response readable in under 2 minutes

## Output Format

**The Big Picture**
[1-2 sentence summary]

**Step by Step**
[Numbered walkthrough]

**Real-World Analogy**
[One relatable comparison]

**Watch Out For**
[One gotcha or common mistake related to this concept]

**What to Explore Next**
[One specific thing to learn that builds on this]
